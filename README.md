# Careers Page Redesign (Co-op Demo)

Demo : 

A clean, responsive, and properly branded refactor of the Software Development Co-op page. 

### Why This Refactor?
* **Alignment & Layout Fixes:** Replaced broken grid/container shifts across viewports with a robust, centered Tailwind CSS layout.
* **Brand Integrity:** Added a custom SVG branded favicon (replacing the generic third-party ATS pink template) and cleaned up typography.
* **Clutter Reduction:** Removed distracting emojis and misaligned em-dashes that detract from candidate conversion.

### Tech Stack
* HTML5 / Tailwind CSS via CDN
* Responsive Mobile-First Design
